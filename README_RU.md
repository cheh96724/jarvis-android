# JARVIS для Redmi Note 13 — прототип 0.1

Первый бесплатный прототип голосового помощника для Android. Проект написан на Kotlin без сторонних библиотек.

## Что уже задумано в версии 0.1

- голосовая активация по фразе «Джарвис» / «Джервис»;
- русская озвучка ответов через системный TextToSpeech;
- команды: открыть YouTube, Telegram, Chrome, настройки и часы;
- запросы: время, дата, заряд батареи, список команд;
- постановка будильника через системное приложение часов;
- уведомление foreground service с кнопкой выключения.

## Важные ограничения прототипа

1. Это ещё не полноценный аналог Siri/JARVIS и не подключён к большой языковой модели. Умные ответы, диалоговая память и поиск в интернете — следующие этапы.
2. Распознавание использует системный Android SpeechRecognizer и пытается предпочесть офлайн-распознавание, если оно доступно. Если на телефоне нет офлайн-пакета русского языка, сервис распознавания может использовать интернет.
3. SpeechRecognizer не является специализированным движком распознавания ключевых слов и не гарантирует надёжное круглосуточное прослушивание. Возможны повышенный расход батареи, паузы и остановки HyperOS. В следующей версии лучше заменить детектор фразы на отдельный локальный движок.
4. Для соблюдения правил Android микрофон запускается только после ручного нажатия «Активировать Джарвиса» в открытом приложении. Затем активный режим отображается постоянным уведомлением. Android/HyperOS могут ограничивать работу при энергосбережении или закрытии приложения.
5. Код не записывает распознанные фразы в отдельный журнал и не имеет разрешения на контакты или звонки.

## Сборка APK

Проект использует Android Gradle Plugin 8.7.3, Gradle 8.9, JDK 17 и Android SDK 35.

- Откройте папку проекта в Android Studio и соберите `app` → `assembleDebug`, либо
- используйте приложенный GitHub Actions workflow `.github/workflows/android.yml`; после успешной сборки APK появится в артефактах запуска workflow под именем `jarvis-debug-apk`.

Получившийся `app-debug.apk` — отладочный APK, который можно установить вручную на личный телефон. Он не подписан для публикации в Google Play.
